01

1. Что такое HTML?

HTML (HyperText Markup Language) — это скелет вашей веб-страницы. Он говорит браузеру, где должен быть заголовок, где абзац, а где картинка.

💡 Запомните: Все элементы HTML пишутся в угловых скобках. Открывающий тег <h1> и закрывающий </h1>.
Основная структура
<!DOCTYPE html>
<html>
<head>
    <title>Моя страница</title>
</head>
<body>
    <h1>Заголовок</h1>
    <p>Это абзац текста</p>
</body>
</html>
02

2. Заголовки и параграфы

Заголовки — это <h1> (самый большой) до <h6> (самый маленький). Параграфы создаются тегом <p>.

Пример
<h1>Главный заголовок</h1>
<h2>Подзаголовок</h2>
<p>Это обычный текст.</p>
03

3. Основы CSS (стили)

CSS отвечает за внешний вид: цвет, размер, отступы. Он подключается в <head> внутри тега <style>.

CSS
<style>
    h1 { color: blue; }
    p  { color: green; }
</style>
💡 Подсказка: В фигурных скобках { } вы указываете свойство (например, color), а после двоеточия — его значение (например, blue).
04

4. Списки

Неупорядоченный список создается тегом <ul>, а каждый элемент — тегом <li>.

Пример списка
<h2>Мои дела</h2>
<ul>
    <li>Купить продукты</li>
    <li>Сделать ДЗ</li>
    <li>Прочитать книгу</li>
</ul>

1. Flexbox: Гибкая верстка

Flexbox — это способ выравнивания элементов. Он позволяет легко размещать блоки в ряд или в колонку.

💡 Запомните: Чтобы включить Flexbox, родительскому контейнеру нужно задать свойство display: flex.
Основы Flexbox
.container {
    display: flex;           /* Включаем Flexbox */
    justify-content: space-around; /* Распределяем элементы */
    padding: 20px;
}

.box {
    width: 100px;
    height: 100px;
    background: #6C63FF;
}
